# Face Lock Assistant

Минимальный MVP для Windows: программа смотрит в камеру ноутбука, распознает лицо владельца и блокирует рабочую станцию, если владельца слишком долго нет перед камерой.

Проект не разблокирует Windows автоматически. Авто-разблокировка небезопасна для такого сценария и обычно ограничена или запрещена операционной системой.

## Что делает программа

- Открывает камеру ноутбука.
- Проверяет кадр каждые 1-2 секунды.
- Сбрасывает счётчик, когда видит владельца.
- Блокирует Windows, если владельца нет дольше `ABSENCE_SECONDS_BEFORE_LOCK` секунд.
- После блокировки ждёт ручную разблокировку Windows.
- После ручной разблокировки даёт защитную паузу `UNLOCK_GRACE_SECONDS`, чтобы экран не заблокировался повторно сразу.
- Записывает неизвестные лица в лог и может сохранять снимки.
- Ограничивает частоту снимков неизвестного лица, чтобы папка `snapshots/` не забивалась.

## Запуск

Обычный запуск:

```powershell
python main.py
```

Если `python` указывает не на `.venv`, `main.py` сам попробует перезапуститься через:

```text
.\.venv\Scripts\python.exe
```

Остановить программу можно сочетанием `Ctrl+C`.

## Безопасная самопроверка

Проверка окружения, камеры и распознавания без блокировки Windows и без сохранения снимков:

```powershell
python main.py --self-test
```

Диагностика разных детекторов лиц:

```powershell
python main.py --diagnose-detectors
```

## Фото владельца

Скрипт теперь поддерживает несколько эталонных фото владельца. Он проверяет все `.jpg`, `.jpeg`, `.png` из папки:

```text
known_faces/
```

Для лучшего распознавания добавьте несколько фото:

```text
known_faces/
  nikolay_front.jpg
  nikolay_monitor.jpg
  nikolay_keyboard.jpg
  nikolay_left.jpg
  nikolay_right.jpg
```

Сделайте фото в обычных рабочих условиях:

- прямо в камеру;
- взгляд на монитор;
- взгляд вниз на клавиатуру;
- лёгкий поворот головы влево;
- лёгкий поворот головы вправо;
- с тем освещением, при котором вы обычно работаете.

Обычная веб-камера не делает настоящий 3D-скан лица. Для 3D/IR-разблокировки лучше использовать Windows Hello с совместимой камерой.

## Захват фото через камеру

Можно сделать одно фото владельца отдельным скриптом:

```powershell
python capture_owner.py
```

Откроется окно камеры:

- `Space` — сохранить текущий кадр;
- `Q` или `Esc` — выйти без сохранения.

По умолчанию снимок сохраняется как:

```text
known_faces/nikolay.jpg
```

Если появляется ошибка чтения кадра, закройте Teams, Zoom, браузерные вкладки с камерой и другие программы, которые могут использовать веб-камеру.

## Мастер сканирования лица

Чтобы собрать несколько фото под разными углами, запустите:

```powershell
python scan_owner.py
```

Скрипт покажет окно камеры, нарисует овал лица и пошагово попросит:

- посмотреть прямо;
- посмотреть на монитор;
- посмотреть вниз на клавиатуру;
- повернуть голову немного влево;
- повернуть голову немного вправо;
- слегка поднять голову;
- принять обычную рабочую позу.

Клавиши:

- `Space` — сохранить текущий шаг;
- `S` — пропустить шаг;
- `Q` или `Esc` — выйти.

Фото сохраняются в `known_faces/` с именами вида:

```text
nikolay_front.jpg
nikolay_keyboard.jpg
nikolay_left.jpg
```

После этого `main.py` будет сверять лицо со всеми фото из `known_faces/`.

## Настройки

Настройки находятся в `config.py`:

```python
CAMERA_INDEX = 0
ABSENCE_SECONDS_BEFORE_LOCK = 10
UNLOCK_GRACE_SECONDS = 60
CHECK_INTERVAL_SECONDS = 1
DETECTOR_BACKEND = "mtcnn"
SELF_TEST_SECONDS = 5
SAVE_UNKNOWN_FACE_SNAPSHOT = True
UNKNOWN_FACE_SNAPSHOT_COOLDOWN_SECONDS = 10
PAUSE_SECONDS_AFTER_LOCK = 1800
LOCK_MIN_WAIT_BEFORE_UNLOCK_CHECK_SECONDS = 5
LOCK_STATE_CHECK_INTERVAL_SECONDS = 5
LOCKED_STATUS_PRINT_INTERVAL_SECONDS = 10
KNOWN_FACES_DIR = "known_faces"
KNOWN_FACE_PATH = "known_faces/nikolay.jpg"
```

Главные параметры:

- `ABSENCE_SECONDS_BEFORE_LOCK`: сколько секунд подряд владелец должен отсутствовать, чтобы заблокировать Windows.
- `UNLOCK_GRACE_SECONDS`: защитная пауза после ручной разблокировки; в это время повторная блокировка запрещена.
- `PAUSE_SECONDS_AFTER_LOCK`: максимальное ожидание после блокировки. `1800` секунд = 30 минут.
- `LOCK_MIN_WAIT_BEFORE_UNLOCK_CHECK_SECONDS`: минимальная пауза после команды блокировки перед проверкой, разблокировал ли пользователь Windows.
- `LOCK_STATE_CHECK_INTERVAL_SECONDS`: как часто проверять ручную разблокировку Windows.
- `UNKNOWN_FACE_SNAPSHOT_COOLDOWN_SECONDS`: минимальная пауза между снимками неизвестного лица.
- `DETECTOR_BACKEND`: детектор лиц DeepFace. На этом ноутбуке `mtcnn` показал себя лучше, чем `opencv` и `ssd`.

## Статусы

- `OWNER_PRESENT`: владелец распознан.
- `NO_FACE`: лицо не найдено.
- `UNKNOWN_FACE`: лицо найдено, но оно не совпало с владельцем.
- `LOCKED_WAIT`: Windows заблокирован, скрипт ждёт ручную разблокировку.
- `UNLOCK_GRACE`: Windows разблокирован, идёт защитная пауза перед повторной блокировкой.

## Ограничения

- Только Windows.
- Без авто-разблокировки Windows.
- Одна камера.
- Качество распознавания зависит от света, камеры, угла лица и качества эталонных фото.
- Если лицо сильно наклонено вниз или закрыто, обычная веб-камера может не распознать владельца.
