# Face Lock Assistant

Минимальный MVP для Windows: программа смотрит в камеру ноутбука, распознает лицо владельца и блокирует рабочую станцию, если владельца слишком долго нет перед камерой.

Проект не разблокирует Windows автоматически. Авто-разблокировка небезопасна для такого сценария и обычно ограничена или запрещена операционной системой.

## Что делает программа

- Открывает камеру ноутбука.
- Проверяет кадр каждые 1-2 секунды.
- Выводит текущий статус в консоль.
- Ничего не делает, пока владелец находится перед камерой.
- Блокирует Windows, если владельца нет дольше `ABSENCE_SECONDS_BEFORE_LOCK` секунд.
- Делает паузу после блокировки, чтобы не продолжать сразу активно обрабатывать кадры.
- Записывает события с неизвестными лицами в лог и может сохранять снимки.
- Ограничивает частоту снимков неизвестного лица, чтобы папка `snapshots/` не забивалась.

## Важное про версию Python

Для скрипта `capture_owner.py` нужен только OpenCV. Его можно использовать с Python 3.14.4.

Для основного распознавания через DeepFace лучше использовать Python 3.11 или 3.12, потому что DeepFace тянет TensorFlow/tf-keras, а эти пакеты часто отстают по поддержке самых новых версий Python.

В этом проекте уже создано виртуальное окружение `.venv` на Python 3.12. `main.py` умеет автоматически перезапускать себя через `.venv`, даже если VS Code сначала запускает файл через глобальный Python 3.14.

## Фото владельца

Есть два способа подготовить фото владельца.

Способ 1: сделать фото через отдельный скрипт:

```powershell
python capture_owner.py
```

Откроется окно камеры:

- нажмите `Space`, чтобы сохранить текущий кадр;
- нажмите `Q` или `Esc`, чтобы выйти без сохранения.

Если появляется ошибка чтения кадра, закройте Teams, Zoom, браузерные вкладки с камерой и другие программы, которые могут использовать веб-камеру. Затем запустите `capture_owner.py` снова.

Скрипт сохранит фото сюда:

```text
known_faces/nikolay.jpg
```

Если файл уже существует, новый снимок заменит старый.

Способ 2: положить фото вручную:

```text
known_faces/nikolay.jpg
```

Лучше использовать обычное фото в анфас с хорошим освещением. MVP поддерживает одно фото владельца.

## Настройки

Настройки находятся в `config.py`:

```python
CAMERA_INDEX = 0
ABSENCE_SECONDS_BEFORE_LOCK = 15
CHECK_INTERVAL_SECONDS = 1
SAVE_UNKNOWN_FACE_SNAPSHOT = True
UNKNOWN_FACE_SNAPSHOT_COOLDOWN_SECONDS = 10
PAUSE_SECONDS_AFTER_LOCK = 20
KNOWN_FACE_PATH = "known_faces/nikolay.jpg"
```

Что означают новые настройки:

- `UNKNOWN_FACE_SNAPSHOT_COOLDOWN_SECONDS`: минимальная пауза между снимками неизвестного лица.
- `PAUSE_SECONDS_AFTER_LOCK`: пауза после вызова блокировки Windows.

## Статусы

- `OWNER_PRESENT`: владелец виден в кадре.
- `NO_FACE`: лицо не найдено.
- `UNKNOWN_FACE`: лицо найдено, но оно не совпало с лицом владельца.

События с неизвестными лицами записываются сюда:

```text
logs/app.log
```

Снимки сохраняются сюда:

```text
snapshots/
```

## Тестирование

Ручные проверки MVP:

1. Запустите `python capture_owner.py`. Камера должна открыться, а фото должно сохраниться после нажатия `Space`.
2. Запустите программу без камеры. Должна появиться понятная ошибка о недоступной камере.
3. Запустите программу без `known_faces/nikolay.jpg`. Должна появиться понятная ошибка о недостающем фото владельца.
4. Запустите программу с камерой. Камера должна открыться, а в консоли должны появляться статусы.
5. Сядьте перед камерой. Статус должен стать `OWNER_PRESENT`.
6. Выйдите из кадра. Через 15 секунд Windows должен заблокироваться.
7. После блокировки программа должна сделать паузу на `PAUSE_SECONDS_AFTER_LOCK` секунд.
8. Попросите другого человека встать перед камерой. Программа должна записать событие в лог и сохранить снимок, если сохранение снимков включено.
9. При длительном неизвестном лице снимки должны сохраняться не чаще, чем раз в `UNKNOWN_FACE_SNAPSHOT_COOLDOWN_SECONDS` секунд.
10. Оставьте программу работать 10-15 минут.
11. Проверьте ложные срабатывания при плохом освещении, в очках и при повороте головы.

## Ограничения

- Только Windows.
- Без графического интерфейса, кроме простого окна предпросмотра в `capture_owner.py`.
- Без режима Windows-службы.
- Одна камера.
- Одно фото владельца.
- Качество распознавания зависит от освещения, качества камеры и фотографии владельца.
- Скрипт не делает и не должен делать автоматическую разблокировку Windows.
